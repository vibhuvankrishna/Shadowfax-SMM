# Exact conversation export required for submission

The official assignment requires the complete, unedited AI conversation, including every prompt and response. The repository can preserve the substantive implementation request and audit request, but it cannot safely manufacture an exact platform transcript.

To create the official transcript:

1. Open this full Codex conversation and scroll to the beginning.
2. Use `Ctrl+P`.
3. Select **Save as PDF**.
4. Enable the option to print all pages, if shown.
5. Save the resulting PDF with the roll-number-at-the-end naming convention.
6. Open the saved PDF and verify that the first prompt, every response, attachments/references, and final response are present without clipped or missing pages.
7. Combine that conversation PDF with the final assignment report if the submission portal requires one single PDF.

Do not replace the exact export with a summary or reconstructed transcript.
